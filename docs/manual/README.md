# Moonglow Viewer: User Manual

Moonglow Viewer shows the models, walkmeshes, textures and blueprints of
Neverwinter Nights: Enhanced Edition, lit the way the game lights them,
with their emitters and visual effects running. It decompiles and compiles
models, edits a model's ASCII source while the view follows each edit, and
renders pictures and galleries from the command line.
